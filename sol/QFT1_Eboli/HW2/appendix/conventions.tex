\section{Conventions}

\subsection{Metric}

There are two choices of metric, 
\begin{align}
    g_-=\textnormal{diag}\mqty(-&+&+&+),\ \ \ g_+=\textnormal{diag}\mqty(+&-&-&-)
\end{align}
I will always use $g_-$. This changes a lot of signs in a lot of places, as example,
\begin{align}
    \mathcal L = g_+^{\mu\nu}\frac12\partial_\mu \phi^\ast\partial_\nu\phi-V\qty[\phi,\phi^\ast]= -g_-^{\mu\nu}\frac12\partial_\mu \phi^\ast\partial_\nu\phi-V\qty[\phi,\phi^\ast]
\end{align}

Physics should be invariant under conventions, so they don't matter, as long as you know which conventions 
you are using and are consistent.

\subsection{Levi-Civita}

The Levi-Civita is the (unique) totally antisymmetric four-pseudo-tensor, $\epsilon_{\alpha\beta\mu\nu}$, there are two possible 
choices of normalization,
\begin{align}
    \epsilon^+_{0123}=1,\ \ \ \epsilon^-_{0123}=-1
\end{align}
I will always use $\epsilon^+$. We define also the spatial Levi-Civita by restricting the covariant one,
\begin{align}
    \epsilon_{ijk} \coloneq \epsilon_{0ijk}
\end{align}

\subsection{Creation and annihilation operators}

When expanding the field in normal modes, there is a choice of normalization of the integral,
\begin{align}
    \phi\qty(x)=\int\frac{\dd[3]{\vb p}}{N_{\vb p}}\qty(a\qty(\vb p)\e^{\im x\cdot p}+b^\dagger\qty(\vb p)\e^{-\im x\cdot p})
\end{align}
some common choices are,
\begin{align}
    N_{\vb p} = \begin{cases}\qty(2\pi)^32\omega_{\vb p}\\ \qty(2\pi)^3\sqrt{2\omega_{\vb p}}\\ \sqrt{\qty(2\pi)^32\omega_{\vb p}}\end{cases}
\end{align}
this changes the commutation relation of the operators as,
\begin{align}
    \comm{a\qty(\vb p)}{a^\dagger\qty(\vb k)} = \frac{N_{\vb p}^2}{\qty(2\pi)^32\omega_{\vb p}}\delta^{\qty(3)}\qty(\vb p-\vb k)
\end{align}
and also the definition of a momentum eigenstate,
\begin{align}
    \ket{\vb p} = \frac{\qty(2\pi)^32\omega_{\vb p}}{N_{\vb p}}a^\dagger\qty(\vb p)\ket0,\ \ \ \braket{\vb k}{\vb p} = 2\omega_{\vb p}\qty(2\pi)^3\delta^{\qty(3)}\qty(\vb k-\vb p)
\end{align}

I will always use $N_{\vb p}=\qty(2\pi)^32\omega_{\vb p}$.
